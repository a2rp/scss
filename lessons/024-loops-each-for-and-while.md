# 024 — Loops: each, for, and while

## Learning goals

After this lesson, you should be able to:

- Explain how Sass loops generate repeated styles during compilation.
- Use **@each** to iterate over a list or map.
- Use **@for** to count through a numeric range.
- Distinguish **to** from **through** in a **@for** loop.
- Use **@while** when repetition depends on a changing condition.
- Choose the clearest loop for a task and avoid unbounded loops.

## 1. What are Sass loops?

A loop evaluates a block of Sass statements multiple times. This is useful when writing many similar rules or declarations whose values vary in a predictable way.

Sass runs loops during compilation. The browser receives the CSS generated by the loop; it does not receive the loop itself.

~~~scss
$sizes: 0.75rem, 1rem, 1.5rem;

@each $size in $sizes {
  .text-#{$size} {
    font-size: $size;
  }
}
~~~

Each list value runs the block once. The variable **$size** holds the current item during that iteration. Interpolation inserts the value into the selector.

Use a loop when it makes repeated styles easier to maintain. For only a few unrelated rules, writing them directly may be clearer.

## 2. Use @each with a list

The **@each** rule runs once for every item in a list.

~~~scss
$spaces: 0.25rem, 0.5rem, 1rem, 2rem;

@each $space in $spaces {
  .gap-#{$space} {
    gap: $space;
  }
}
~~~

This generates four selectors: **.gap-0.25rem**, **.gap-0.5rem**, **.gap-1rem**, and **.gap-2rem**. Each rule gets the corresponding gap value.

In real projects, using raw values in class names is often not desirable. You can store a name and a value together instead, as in the next example.

## 3. Use @each with a map

A map stores key-value pairs. With two loop variables, **@each** assigns the key to the first variable and its value to the second.

~~~scss
$colors: (
  "primary": #2457c5,
  "success": #16803c,
  "danger": #c43232
);

@each $name, $color in $colors {
  .text-#{$name} {
    color: $color;
  }
}
~~~

Generated CSS:

~~~css
.text-primary {
  color: #2457c5;
}

.text-success {
  color: #16803c;
}

.text-danger {
  color: #c43232;
}
~~~

Maps are useful when each generated class needs both a readable name and a related value.

## 4. Destructure a list of lists

If each item in a list contains several values, **@each** can assign them to multiple variables.

~~~scss
$icon-sizes: (
  "search" 1rem,
  "menu" 1.25rem,
  "close" 0.875rem
);

@each $name, $size in $icon-sizes {
  .icon-#{$name} {
    inline-size: $size;
    block-size: $size;
  }
}
~~~

Each inner list is unpacked into **$name** and **$size** for that iteration. Make the structure consistent: every item should provide the values expected by the loop.

## 5. Use @for for a numeric sequence

The **@for** rule counts from one number to another. Use **through** when the final number should be included.

~~~scss
@for $step from 1 through 4 {
  .space-#{$step} {
    margin-block-start: $step * 0.25rem;
  }
}
~~~

This runs with **$step** equal to **1**, **2**, **3**, and **4**, generating four rules.

Use **to** when the final number should be excluded:

~~~scss
@for $step from 1 to 4 {
  .step-#{$step} {
    order: $step;
  }
}
~~~

This loop runs for **1**, **2**, and **3**. The difference is important:

| Range | Values when starting at 1 and ending at 4 |
| --- | --- |
| **from 1 through 4** | 1, 2, 3, 4 |
| **from 1 to 4** | 1, 2, 3 |

Choose the range that matches the number of iterations you need. An off-by-one range can create a missing or extra selector.

## 6. Count down with @for

A **@for** loop can count downward as well as upward.

~~~scss
@for $layer from 3 through 1 {
  .layer-#{$layer} {
    z-index: $layer;
  }
}
~~~

This loop uses **3**, then **2**, then **1**. The ending value is still included because the range uses **through**.

## 7. Use @while for condition-based repetition

The **@while** rule repeats its block while a condition is true. You must change a value in the loop so the condition eventually becomes false.

~~~scss
$step: 1;

@while $step <= 3 {
  .level-#{$step} {
    padding: $step * 0.5rem;
  }

  $step: $step + 1;
}
~~~

The values **1**, **2**, and **3** each produce a rule. After the third iteration, **$step** becomes **4**, so the condition is false and the loop stops.

A **@while** loop is flexible, but it is easier to make a mistake in its condition or update. Prefer **@each** when iterating over known values, or **@for** when counting through a numeric range.

## 8. Combine loops with CSS output

Loops are especially useful for generating utility classes from a small Sass data set.

~~~scss
$directions: (
  "top": block-start,
  "bottom": block-end,
  "left": inline-start,
  "right": inline-end
);

@each $name, $property in $directions {
  .margin-#{$name}-small {
    margin-#{$property}: 0.5rem;
  }
}
~~~

Each map entry supplies the readable class suffix and the logical property used in the declaration. This produces styles that follow the writing direction of the page.

Use generated classes deliberately. Large or unbounded data sets can create a lot of output CSS.

## 9. Choosing the right loop

| Loop | Best suited to | Example |
| --- | --- | --- |
| **@each** | Process every known item in a list or map. | Theme colors, breakpoints, spacing tokens. |
| **@for** | Repeat a known number of times or generate a numeric sequence. | Numbered spacing or layer classes. |
| **@while** | Continue until a condition changes to false. | Repeated calculation with a stopping condition. |

Prefer the loop that communicates the data and stopping rule directly. For a known collection, **@each** is usually clearest. For a simple integer range, use **@for**. Use **@while** only when a condition-based loop is genuinely needed.

## 10. Common mistakes

### Forgetting interpolation in generated selectors

Sass values need interpolation when inserted into selector text.

~~~scss
@each $name in "primary", "danger" {
  .button-#{$name} {
    display: inline-flex;
  }
}
~~~

Without interpolation, Sass does not insert the variable into the selector as intended.

### Confusing to and through

**to** excludes the ending number; **through** includes it. Check the first and last iteration before relying on the generated output.

### Forgetting to update a @while condition

If a **@while** loop never changes the values used in its condition, it may never stop. Initialize the loop variable before the block and update it on every iteration.

### Using a loop for unrelated styles

A loop should simplify repetition. If each style has different structure and meaning, explicit rules may be easier to read.

### Generating too much CSS

Every iteration can produce output. Keep the input list or range focused on styles the project actually needs.

## 11. Practice

1. Use **@each** to generate a class for each value in a short spacing list.
2. Use **@each** with a map to generate a named color class for each key-value pair.
3. Use **@for** with **through** to create five numbered classes.
4. Change the same loop to **to** and write down which value is excluded.
5. Write a **@while** loop that starts at **1**, creates three classes, and increments its counter.
6. Explain why **@each** or **@for** is usually clearer than **@while** when the iteration count is already known.

## Key takeaways

- Sass loops repeat statements during compilation and generate ordinary CSS.
- **@each** iterates over lists, maps, or structured list values.
- **@for** iterates through a numeric range; **to** excludes the endpoint and **through** includes it.
- **@while** repeats until its condition becomes false, so its loop state must be updated.
- Prefer **@each** for known collections and **@for** for numeric ranges.
- Keep generated output focused so loops do not create unnecessary CSS.
